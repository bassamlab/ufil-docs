Installation via Debian Packages

This guide describes how to install Ufil using prebuilt Debian (.deb) packages via apt.

This method is intended for:

  • Native installations on a host system

  • Integration into custom Docker images

  • Deployment on production systems

Warning

This installation method is not yet available. Support for Debian packages will be provided in a future release.

Please use one of the following methods instead:

  • Native source installation

  • Docker-based installation
