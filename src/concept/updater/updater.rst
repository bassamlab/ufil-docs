Updater
=======

This sections below provides an overview of the updater used in Ufil and are meant to gain deeper underatnding of the underliging methmatica approche to creat the object. We grouped them into four main categories: state, dimension, classification and existance. Each category contains a set of algorithms that are used to update the state of the object, determine its dimensions, classify it, and determine its existance.
