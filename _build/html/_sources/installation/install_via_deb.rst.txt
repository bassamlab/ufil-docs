.. _install_via_deb:

Installation via Debian Packages
=================================

This guide describes how to install **Ufil** using prebuilt Debian
(``.deb``) packages via ``apt``.

This method is intended for:

- Native installations on a host system
- Integration into custom Docker images
- Deployment on production systems

.. warning::

   This installation method is not yet available.
   Support for Debian packages will be provided in a future release.

   Please use one of the following methods instead:

   - :ref:`Native source installation <install_from_source_natively>`
   - :ref:`Docker-based installation <_install_from_source_via_docker>`
